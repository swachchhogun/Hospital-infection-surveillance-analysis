# Data access

The hospital microbiology dataset used in this project is **not published in this repository**.

The repository contains the analysis code, documentation and report, but not the underlying hospital register. This keeps the public repository separate from the source data used during the internship.

To run the notebook, place the authorised local workbook in your own working environment and update the file path in the first data-loading cell if necessary.

Do not add the hospital dataset, patient-level records, raw extracts or other confidential files to this repository.
