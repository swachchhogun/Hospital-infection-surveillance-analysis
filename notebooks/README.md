# Analysis notebook

`Analysis_Notebook.ipynb` is the main executable notebook for the statistical analysis.

Run it from top to bottom in an authorised environment with the hospital dataset available locally. The source dataset is intentionally not stored in this repository.

The notebook covers:
- cleaning/analysis setup
- resistance phenotype profiling
- chi-square and Cramer's V
- logistic regression
- prediction and validation
- SPC p-chart and trend testing
- analysis figures
