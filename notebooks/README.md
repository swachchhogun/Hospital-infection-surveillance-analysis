# Analysis notebook

`Analysis_Notebook.ipynb` is the main executable notebook for the statistical analysis.

Run it from top to bottom in an authorised environment with the approved cleaned hospital dataset available locally. The source dataset is intentionally not stored in this public repository.

The notebook covers:

1. setup and data-integrity checks
2. resistance phenotype profiling
3. chi-square tests and Cramer's V
4. multivariable logistic regression
5. internal prediction and validation
6. SPC p-chart and trend testing
7. report figures

The accompanying `docs/Analysis_Code_Walkthrough.md` explains the code and statistical reasoning step by step.

Generated aggregate tables belong in `results/`; report-ready figures belong in `figures/`.
