# Publishing checklist

## Keep in the repository

- `notebooks/Analysis_Notebook.ipynb`
- `docs/Analysis_Code_Walkthrough.md`
- `docs/Dashboard_Build_Guide.md`
- `docs/Methodology_Summary.md`
- `README.md`
- `DATA_ACCESS.md`
- selected figures/screenshots, if cleared for publication

## Add manually when ready

The connected GitHub tools used here support text/code files directly, but the final report DOCX/PDF and Power BI PBIX are binary files. Add these through GitHub's web upload interface:

- `report/Infection_Surveillance_Report_FINAL.pdf`
- optionally `report/Infection_Surveillance_Report_FINAL.docx`
- `dashboard/Infection_Surveillance_Dashboard.pbix`

Only add the PBIX/report if you are permitted to publish the internship materials and hospital name publicly.

## Do not add

- raw hospital data
- cleaned hospital spreadsheets
- patient-level extracts
- confidential screenshots
- temporary Excel files
- duplicate report versions

## Final check

Open the public repository in a private/incognito browser window and confirm that:

1. the README renders correctly;
2. the notebook opens on GitHub;
3. no source dataset is visible;
4. no duplicate drafts are present;
5. the report and dashboard files, if published, are the intended final versions.
